# Journal des versions

## 1.1.0 - 2026-11-12

### Ajouts

- **Taper pour filtrer.** Commencez à taper dans Exposé : seules restent les fenêtres dont le titre, l'identifiant ou le nom de l'app contient le texte (sans tenir compte des majuscules ni des accents). Retour arrière efface, Échap vide le filtre avant de fermer, Entrée ouvre la fenêtre choisie ; Espace l'ouvre aussi tant que vous n'avez rien tapé.
- **Quatre styles**, ceux de qDock et qCenter : Omarchy, Cupertino, Redmond et Plasma.

### Changements

- **qExposé suit le style de qDock** quand son propre `style` n'est pas réglé ; sans qDock, Cupertino reste le style par défaut.
- **Le `style` `"mac"` s'appelle maintenant `"cupertino"`** ; l'ancien nom se lit encore.
