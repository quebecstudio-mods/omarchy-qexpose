# Changelog

## 1.1.0 - 2026-11-12

### Added

- **Type to filter.** Start typing in Exposé: only the windows whose title, app id or app name contains the text stay (case and accents ignored). Backspace erases, Escape clears the filter before closing, Enter opens the selected window; Space opens it too until you start typing.
- **Four styles**, qDock's and qCenter's: Omarchy, Cupertino, Redmond and Plasma.

### Changed

- **qExposé follows qDock's style** when its own `style` is not set; without qDock, Cupertino stays the default.
- **`style` `"mac"` is now `"cupertino"`**; the old name still reads.
